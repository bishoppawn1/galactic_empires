# Aegis Directorate unit art

Top-down unit sprites generated for the Aegis Directorate roster. The shared white ceramic armor, gold shield hardware, and cyan power systems distinguish Aegis units from the Human Coalition at production-card, battlefield, and galaxy-map scales.

The Farcast Scout uses a narrow, engine-forward silhouette for its high-speed reconnaissance role. The Resonance Anchor uses broad gold phase vanes and a luminous cyan core; its Tier 2 counterpart retains that silhouette at cruiser scale.
