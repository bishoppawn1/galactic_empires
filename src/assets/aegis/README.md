# Aegis Directorate unit art

Top-down unit sprites generated for the Aegis Directorate roster. The shared white ceramic armor, gold shield hardware, and cyan power systems distinguish Aegis units from the Human Coalition at production-card, battlefield, and galaxy-map scales.

The Farcast Scout uses a narrow, engine-forward silhouette for its high-speed reconnaissance role. Each Tier 2 successor has its own larger cruiser artwork: expanded troop vaults, shield rings, twin lances, flak-turret arrays, and concentric resonance hardware make the upgrade visible before the player reads its label.
