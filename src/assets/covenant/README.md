# Iron Covenant sprites

These transparent top-down sprites were generated with the built-in image generation tool as two ordered chroma-key sprite sheets, then cropped and processed with the imagegen skill's chroma-removal helper. Ground and ship assets retain their shared gunmetal, blue-light, and furnace-orange visual language.

The later Surveyor Skiff and Lockstep Frigate additions were generated as individual chroma-key assets in the same faction language. The Surveyor is a compact engine-heavy scout, while the Lockstep hull carries paired phase-control projector arms and is reused at a larger scale for its Tier 2 Cruiser.
